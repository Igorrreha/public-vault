# Разбор
## Предисловие
Я играл в [Necromerger](https://play.google.com/store/apps/details?id=com.grumpyrhinogames.necromerger&hl=ru&pli=1) **больше месяца**, прокачал Ктулху до 24го левела, прошёл первый ивент **и посмотрел оооочень много рекламы** (о чём, к моему огромному удивлению, не жалею)).

Этот разбор писался с целью понять, как именно у этой игры получилось при максимально лаконичном геймплее сформировать и сохранить напротяжении продолжительного времени мотивацию играть + создать ощущение [[Справедливость в рекламной монетизации|справедливости монетизации]] (несколько дней подряд себя ловил что я по собственной воле смотрю всю рекламу, которую даёт мне игра).
В процессе этого разбора я старался затронуть только ключевые аспекты геймдизайна этой игры, поэтому собирать список всех внутриигровых объектов, описывать геймплей и детально расписывать прогрессии я не стал.
> Крайне рекомендую потыкаться в игру самостоятельно для получения наглядной иллюстрации обсуждаемого ниже

## Игровые действия
1. Взаимодействие с объектами на поле:
	1. Перемещение объектов игрового поля
	2. Мердж объектов игрового поля
	3. Генерация энергии кликом по Некромерджеру
	4. Спавн объекта кликом по спавнеру
	5. Открытие сундука / разморозка миньона
	6. Скармливание объекта Ктулху
2. Покупка объекта
3. Получение награды
4. Перемещение объекта на игровое поле из спец. слота выдачи
## База
1. Главная глобальная цель игры — как можно сильнее раскормить Ктулху (повысить уровень до предела, конкретный уровень не называется)
2. Единственный способ повысить уровень Ктулху — скормить ему достаточное количество объектов игрового поля
3. При скармливании объект уничтожается, а его пищевая ценность "высвобождается" (ресурсы начисляются на счёт, теперь ими можно пользоваться)
4. Ресурсы используются для получения новых объектов игрового поля

>[!info] Мысли
В первом приближении игра представляет из себя что-то вроде симулятора перекупа: геймплей сводится к «купил → преобразовал → продал», просто в обёртке сектантской тематики.
При этом сама экономическая модель достаточно комплексна, она включает в себя несколько видов ресурсов и не позволяет напрямую увеличить количество какого-либо ресурса без задействования других. Даже возможность посмотреть рекламу является конечным ресурсом.
Для получения разных видов ресурсов "продавать" игровые объекты придётся разным "покупателям": использовать в драках для получения рун, либо скармливать ктулху для продвижения по игре, эта дилемма является крайне важным моментом

>[!important] Дилемма продвижения
Для продвижения по игре (прокачке Ктулху → разблокировке нового контента) игрок обязан скармливать игровые объекты. Каждый раз соглашаясь на это он, как бы, жертвует некоторую часть имеющихся у него ресурсов ради того чтобы продвинуться дальше (в ущерб скорости накопления ресурсов).
По ощущениям это сильно напоминает дилемму вывода средств из бизнеса (бизнес заработал 1К прибыли, положить её себе в карман или реинвестировать). Не знаю, закладывали ли это разработчики умышленно, но технически оно тут есть
## Хитро выстроенный баланс
1. Объекты в пространстве игрового поля — это «активы» (объекты, предназначение которых в том, чтобы в конечном итоге принести большее количество ресурсов, чем было потрачено на их покупку)
2. Размер игрового поля ограничивает доступное количество активов, которые игрок может иметь
3. Подавляющее большинство игровых объектов имееют уровень и прогрессию прокачки
4. Прокачка осуществляется при помощи мерджа одинаковых объектов
	- Количество ячеек требуемое для увеличения уровня объекта увеличивается на 1 с каждым уровнем (1 + 1, 2 + 1 + 1, 3 + 2 + 1 + 1 и т.д.)
	- Количество ресурсов требуемое для получения объекта следующего уровня удваивается с каждым уровнем (250, 500, 1К, 2К и т.д.)
5. Прогрессия ценности объектов при этом устроена хитро:
	- Ценность более высокоуровневого объекта растёт не пропорционально количеству потраченных на него ресурсов, а имеет нюансы, заставляющие игрока дополнительно взвешивать: «стоит ли мерджить объекты сейчас»
		- Мясистость и урон объектов (у которых они есть) увеличиваются либо быстрее чем стоимость (> x2), либо с той же скоростью, что по этим параметрам склоняет игрока как можно быстрее мерджить объекты друг с другом (освободить больше пространства, получить большую ценность)
		- Количество производимой маны (где оно есть) удваивается с каждым уровнем только до определённого капа, дальше начинает расти со скоростью < x2, поэтому для максимизации скорости прироста энергии мерджить объекты становится не выгодно
		- При повышении до некоторых уровней у объектов появляются дополнительные свойства, меняющие экономику или сам принцип работы. Прежде всего это касается спавнеров, которые при повышении до 3го лвла начинают с определённым шансом производить объекты другого типа (были только кости скелетов, теперь ещё и плоть зомби), что крайне сильно влияет на расход ресурса пространства и повышает стоимость объектов первого типа (того который производился изначально).
		  Так же в лейтгейме спавнеры можно смерджить в легендарных юнитов, но это уже закапывание в слишком глубокие дебри
6. Фактически, повышение "выгодности" конвертации одного вида ресурса в другой (путём покупки активов) происходит пошагово, каждый шаг при этом требует больше свободного пространства и больше ресурсов

>[!info] Пример — активные спавнеры и мердж
>Могила покупается за 20 рун льда и ставится на игровое поле (занимает пространство).
>Сама по себе она не приносит ресурсы, пищевую ценность так же не имеет.
>Её можно активировать, каждая активация стоит 250 маны и спавнит кость<1> (объект игрового поля, тоже требующий пространство).
>Кость<1> ничего не производит, но занимает пространство. Её можно скормить (получив 1 еды), либо смерджить с костью<1> получив кость<2>, две кости<2> можно смерджить в кость<3> — скелета, который будет производить 1 маны в такт (1К тактов чтобы самоокупиться)
## Любопытство — основной стимул
На повышение уровня [[Любопытство|любопытства]] в игре работают сразу несколько вещей:
1. Возможность посмотреть путь прогресси объектов игроку показывают сразу, как только он поместил объект на своё игровое поле, но в пути показывают только статы, сам внешний вид при этом остаётся загадкой. Усиливает интригу то, что первые уровни прогрессии (в первую очередь, существ) анлокаются достаточно быстро и мозгу игрока есть за что уцепиться, чтобы простроить вектор развития внешнего вида объекта
2. В списках (магазин, список «чемпионов» и «штук») доступные объекты выстраиваются по очереди и их список обрывается на кнопке следующего разблокируемого предмета (игрок видит требуемый уровень Ктулху и может прочитать описание)
3. В окне квестов периодически мелькают задания завязанные на взаимодействие с каким-то объектом, с которым игрок ещё не сталкивался
4. В игре есть бестиарий, где показаны силуэты первого и последнего уровней прогресси всех существ, а за анлок (появление на поле) этих объектов дают вкусный доп. ресурс
5. Игрок видит награду за следующий левелап Ктулху, но часто может прочитать только его краткое описание
## Справедливая рекламная монетизация
Складывается здесь из нескольких факторов:
1. В игре есть только ревардная реклама
2. Реклама — это всегда ограниченный ресурс:
	1. 4 раза в день можно использовать её чтобы пополнить какой-нибудь из баков энергии (уместнее всего, воспринимается как необязательный скип ожидания)
	2. 3 раза в день можно использовать её для открытия специальных бонусных сундуков (воспринимается менее уместно, но позволяет ускорить прохождение игры через покупку донатных штук без доната)
	3. 3 раза в день можно использовать её для разморозки замороженных юнитов (интеграция слабее всего, на мой взгляд, мотивации пользовать мало, т.к. даже юнита предварительно не показывают, но не раздражает, так как можно просто скормить и получить бонусное мясо)
3. Рекламные объекты (2 и 3 из примера выше) спавнятся по прогресс барам мерджа, поэтому для того чтоб их получить нужно ещё поактивничать какое-то время (поэтому спама рекламой нет)
4. Рекламные объекты можно скормить, чтобы получить маленький бонус и не смотреть рекламу
# Итог
 Что я понял из этого разбора? То что мобильная микроигра про кормление ктулху может внезапно оказаться симулятором ведения бизнеса.
 Структуру прогрессии «купил → трансформировал → продал», расписанную выше, определённо можно использовать как шаблон, но выкручивать в кучу разных сторон. Тут целое поле того, с чем можно экспериментировать, например:
  - С набором и формой ресурсов (2d пространство поменять на 3d, использовать сложные формы объектов, использовать несколько разных "пространств")
  - С самим процессом "преобразования" ресурсов (мердж заменить на что-нибудь другое)
  - Со структурой путей от покупки до продажи
